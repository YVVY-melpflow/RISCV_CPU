# 開発日記

## シングルサイクル CPU を作る

### 最初のコミット

1. まずは PC を作る．今はまだ 1 サイクルごとに +4 byte するカウンタ．ProgramCounter.sv を作成．
2. 動きを見たいのでテストベンチを作る．と考えたところで CPU モジュールも作らなければいけないことに気づいたので，CPU.sv を作成．
3. テストベンチを作る．リセットを挿入→解除した後でクロックを複数回入れる．カウンタが進んでいることを確認する．
4. とりあえずカウンタが進むところまで確認できたので最初のコミット．Icarus Verilog で Sim を実行．  

    ```bash
    cd sim # ディレクトリ未登録
    iverilog -o runsim ../testbench/myTestbench.sv ../design/CPU.sv ../design/ProgramCounter.sv -g 2012
    vvp runsim
    ```

   ログは以下のようになった．


## Decoder の追加

1. 命令データが読み込めるようになったので，次はデコードする．まずは ADDI をデコードする．
2. rs1, rd, imm を命令データから取り出す．rs2 や opcode や funct などは一旦考えない．他の命令を実装するときに必要になったら都度追加していくつもり．
3. 命令データをアセンブリから RISC-V ツールを使って作成するように変更．
4. デコード結果を Sim 結果に出力．即値が符号拡張されずに出力されているが，一旦動いたのでここまででコミット．
5. 即値の符号拡張を追加．ADDI は符号拡張．これはデコーダの中で書いてもよかったかもしれない．
6. ログの即値の出力が unsigned になっていたのを修正．

## ResigserFile, ALU の追加

1. RegisterFile の追加．今のところ rs1 と rd のみ．Write Enable も作っていない．ゼロレジスタは作成．
2. ALU の追加．こちらも ADDI にのみ対応．
3. テストケースを少しマシにして実行．できていそう．
4. できていなかった．RegisterFile の読み出し Index が rd になっていたので rs1 に修正．

## テスト環境の作成

1. 一応 ADDI は実行できるようになったはずなので，ここで一度テスト環境を作ることにする．テストベンチのログ出力をテストしやすそうな形式に見直した．
2. ADDI の検証項目を考える．
    - -2048 から +2047 までの加算・減算ができること
    - 演算結果が rd レジスタに保存されていること
    - ゼロレジスタに結果は保存されず，常に 0 が読みだされること
   これくらいだろうか．対応するテストケースを作った．
3. テストケースをまとめてビルドできるようにした．
4. テストケースをまとめて検証できるように Makefile を更新．実行命令ごとの比較テストでどこまでいけるか分からないが...
