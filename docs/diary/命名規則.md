# 命名規則

SystemVerilog コーディング時の命名規則をまとめておく．

- モジュール名は 1 単語目は全て小文字，2 単語目以降はそれぞれの 1 文字目を大文字にする（aaaBbbCcc）
  - CPU や PC など，大文字の書き方が定着しているものは 1 単語目の 1 文字目も大文字にしてよい（ProgramCounter）
- モジュールのインスタンス名には，モジュール名に接頭辞 u_ をつける
- 信号名もモジュール名同様，1 単語目は全て小文字，2 単語目以降はそれぞれの 1 文字目を大文字にする．更に以下の接頭辞を追加する
  - モジュールの入力/出力信号にはそれぞれ i_/o_ の接頭辞をつける
  - モジュール内部の信号には，それぞれ wire か register かによって w_/r_ の接頭辞をつける
- パラメータや define 名は全て大文字で記載する，単語間はアンダーバーで区切る．また，それぞれ P_/D_ の接頭辞をつける
